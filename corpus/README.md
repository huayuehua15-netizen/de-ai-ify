# 金标准语料（corpus）

- **用途**：M1 评分引擎的回归基准（`apps/api/tests/test_corpus.py`），任何权重/词库/检测器改动都必须跑 `pnpm test` 验证。
- **验收线**：AI 样本**均分 ≥ 65**，人写样本**均分 ≤ 35**（docs/DEVELOPMENT.md §5.7、§13.1）。
- **文件**：`{kind}-{lang}.txt`，kind ∈ `ai | human`，lang ∈ `zh | en`；每篇以单独一行 `---` 分隔；`#` 开头行为注释。
- **来源与许可**：全部为本仓库原创撰写（AI 样本为对典型 LLM 文风的人工改写，不含任何真实服务的可识别输出），随仓库以 **MIT** 协议发布，可自由用于训练与评测。

样本规模：AI ≥ 50 篇、人写 ≥ 50 篇（中英混合，各自语言占比用于覆盖双语规则）。

扩充语料时请：新增样本写入对应文件（追加 `---` 分隔），并在 PR 里说明来源许可；**不要**为凑分而修改验收线。
